# Hildr

Hildr is a browser-based third-person RPG prototype built with Three.js.

## Demo

GitHub Pages:

`https://Benjamin-Wegener.github.io/Hildr/`

## Controls

- `W` / `S`: move forward and backward
- `A` / `D`: strafe left and right
- Mouse: rotate the camera
- Right mouse button: hold to rotate the camera
- `Shift`: sprint
- `1`, `2`, `3`: blessings

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
